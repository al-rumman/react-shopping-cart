# React Shopping Cart

Responsive shopping cart built with React + Vite, using Context API (`useReducer`) for global cart state.

## Features
- Product grid with category filter
- Add to cart, increase/decrease quantity, remove items
- Live total item count and total price
- Cart persisted in localStorage
- Mobile-first responsive layout

## Run locally
```bash
npm install
npm run dev
```

## Structure
`components/` UI · `context/` cart state · `data/` mock products · `hooks/` useCart · `App.jsx` · `main.jsx`
